# 루틴바인더 (안드로이드 앱)

3P바인더의 시간관리와 마이루틴식 루틴 신호등을 합친 개인 플래너 앱입니다.

- **오늘**: 루틴 신호등·이모지 체크·쉬는 날, A/B/C 우선순위 할 일, 한 줄 회고
- **시간**: 30분 단위 계획(Plan)/실행(Do) 기록과 시간 사용 분석
- **주간**: 주간 목표, 요일별 루틴 체크표
- **목표**: 사명, 역할별 목표, 백업·복원
- **통계**: 연속 기록일, 30일 달성률, 루틴별 실천율
