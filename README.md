# 3P 바인더 (안드로이드 앱)

사명 · 목표 · 월간 · 위클리(Plan/Do 타임라인) · 우선순위 할 일 · 습관 · 본깨적 독서노트를 담은 개인 플래너 앱입니다.

## APK 받기
1. 위쪽 **Actions** 탭 → 가장 최근 **APK 만들기** 실행을 누릅니다.
2. 맨 아래 **Artifacts**의 `3P-binder-apk`를 내려받아 압축을 풉니다.
3. `3P-binder.apk`를 휴대폰으로 옮겨 설치합니다. (출처를 알 수 없는 앱 설치 허용 필요)

기록은 휴대폰 안에 저장됩니다. 앱의 **사명 → 백업 만들기·공유**로 주기적으로 백업하세요.
